Speed

Intel i5-8250U laptop CPU, 4 cores / 8 threads, 8 GB RAM, no GPU. Everything that happens inside a game is C (the engine, the GA genome, az-v1's agent and this project's network); PyTorch only trains. Measured end to end:

WhatTime
a game, network (sampling, recording) vs GA genome, one core2.9 ms
a game, GA genome vs GA genome0.27 ms
a game, az-v1's searching agent (400 simulations per buy) vs GA genome460 ms
a PPO iteration at the start: 1,500 random self-play games (~210 decisions each) + update + 700 eval games~14 s
a PPO iteration once it plays sensibly (games shorter, fewer decisions)~5–10 s

The network plays a whole game in the time az-v1's agent needs for one simulation of one buy times 30: that speed is what makes learning from millions of games possible. Random play is the slow part: games last until the turn limit or three empty piles, and a random player is asked many more questions per game. That is also why this run uses 1,500 games per iteration instead of rl-v1's 3,000: the first iterations' data did not fit in the 8 GB of memory. Per-iteration times are on the Training tab ("Iteration time").
