Lessons

What this project and earlier ones taught. Newest first.

From this project

  • A teacher is not needed to get off the ground. rl-v1's lessons said that starting RL from a random network "would have spent hours relearning what the genome already knew". The first (aborted) start of this run showed the opposite for the basics: from random weights, self-play alone went from 0% to 45% against Big Money and 20% against the GA genome in 9 iterations (about two minutes), never having played either. Whether it gets past the teacher in the end is what this run is for.
  • Memory, not CPU, limited the start. Random players make long games with many decisions; 3,000 such games per iteration (as in rl-v1) ran an 8 GB laptop out of memory. 1,500 games per iteration fit.

From rl-v1 (this project's parent)

  • You can only beat what you practise against. rl-v1 tied az-v1 head to head until az-v1 joined its league; then it won 55%, and after 2,200 iterations 72%. Here the earlier models join in stage 3.
  • Speed is a feature. 3 ms per game inside the C engine, against 460 ms for az-v1's search: millions of practice games on a laptop.
  • Confirm once, on games never used, with the rival on the same games. This project has its own never-used confirmation set (experiments/confirm.py, a new seed), for the end.

From az-v1

  • Keep one number on data the model never trained on. Here: the evaluation against the GA genome and the bots during stage 1, which the network never trains against, and the win estimate's error on fresh games.
